# 🧩 Scholar Track - Wireframe Design

A wireframe design for the Scholar Track web application, created as part of a group project to define the structure, layout, and user flow before UI development.

## 🎯 Project Purpose
The purpose of this wireframe is to visualize the structure of the Scholar Track system.  
It helps to plan navigation, layout, and user experience in the early design stage.
